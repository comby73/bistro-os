# 05 — Prompts y agentes

## Objetivo

Centralizar la lógica conversacional y asistiva del producto.

## Agentes incluidos

- WhatsApp Reservas.
- Resumen Operativo.
- Análisis de Feedback.
- Agente Comercial.
- QA Validator.
- Agente Cocina.

## Regla

Los agentes no reemplazan validaciones de sistema.  
Primero se validan datos con código, luego la IA puede enriquecer o clasificar.
