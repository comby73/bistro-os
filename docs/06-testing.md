# 06 — Testing

## Estrategia

El MVP incluye tests básicos de validación:

- Lead válido.
- Email inválido.
- Reserva con cantidad inválida.
- Pedido sin items.

## Herramienta

Vitest.

## Comando

```bash
npm run test
```

## Por qué testear

La validación evita que los workflows reciban datos rotos y ayuda a defender el proyecto como mantenible.
