# Contexto del sistema — Bistró OS

Bistró OS es un SaaS para restaurantes de gama media-alta en LATAM.

## Propuesta de valor

Unificar reservas, pedidos, cocina, ventas y automatizaciones en una sola plataforma.

## Usuario objetivo

Dueños, gerentes y equipos operativos de restaurantes con servicio constante, donde la fricción diaria aparece en:

- Reservas dispersas por WhatsApp.
- Pedidos desordenados.
- Falta de visibilidad de cocina.
- Reportes manuales.
- Decisiones basadas en intuición y no en datos.

## Principios

- La IA asiste, no reemplaza decisiones críticas.
- El sistema debe ser modular.
- Cada módulo debe tener entradas, salidas y responsabilidades claras.
- La experiencia visual debe ser premium, clara y sobria.
- La información debe estar preparada para automatizaciones.
