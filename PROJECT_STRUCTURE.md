## Uso recomendado

1. Abrir carpeta en VS Code o Claude Code.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Trabajar módulo por módulo.
5. No conectar credenciales reales hasta revisar `.env.example`.
